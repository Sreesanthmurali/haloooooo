# AFTER HOUR PARTY • HOSTED BY D CARTEL
### Mahaguru Institute of Technology (MIT)

A cinematic, mobile-first Halloween reveal experience built for **D CARTEL** at **Mahaguru Institute of Technology**.

---

## 🎃 Features

- **Interrogation Stage:** Asks for student name and college roll number (`vpeXXcs/ds/me/XXX`).
- **Gothic Skull Altar:** Displays the bloodbound candle skull shrine with glowing jack-o'-lanterns.
- **Cinematic Stage:** "D CARTEL PRESENTS" reveal with metallic dragon-sword glint and animated typography.
- **Jump Scare Experience:** Mobile-first screamer ghost apparition accompanied by *Insidious* title audio, screen quake, claw slashes, and haptic vibration (`navigator.vibrate`).
- **The Grand Poster Reveal:** Smooth dismissal into the vintage horror poster in full screen, looping *Soulful Spooky Halloween* soundtrack.
- **Sound Controls & Fullscreen:** Interactive sound toggle and native fullscreen mode.

---

## 🛠️ Tech Stack

- Pure Semantic HTML5 & Mobile-First CSS3 (Fluid `clamp()` typography, GPU-accelerated keyframe animations)
- Vanilla JavaScript (ES6+, Web Audio API procedural synthesis, zero external runtime dependencies)
- Custom sound design with audio streaming
